Questions

Do I need an account to read the data?

No. Every feed under /data/ is a public JSON file with no key and no login. You can fetch it from a script, a notebook, or a SIEM.

Is the data really free, and where does it come from?

Yes. We collect from official or public sources such as NVD, CISA KEV, GitHub Advisories, Exploit-DB, CERT-EU, Wiz Research, ransomware.live, OpenPhish, Microsoft, Ubuntu, and FIRST EPSS. The status page lists every source, its cadence, and its upstream URL. Upstream terms still apply to your use of the data.

Why manual invoices instead of card checkout?

Billing is deliberately simple during the beta. It keeps payment data out of the platform while the hosted console is being finished. Card checkout is planned after that.

Where would my watchlist and alerts live?

In a private Cloudflare D1 database, never in this Git repository. Public files will continue to contain only public threat data. Today there is no account system, so there is nothing private to store yet.

Can I run the collectors myself?

Yes. The repository is public and the collectors use only the Python standard library. See the GitHub repository for the scripts and the field contract.
