Program updates go through a pull request

The old write-in-a-form admin path has been retired.

Why

The retired admin API committed straight to main with a long-lived token, which bypassed review and the feed checks. main is now protected: every change arrives as a pull request that must pass the data, Python, and unit checks before it can merge.

How to add or correct a program

  • Open an issue with the program name, platform, and in-scope domains: new scope issue.
  • Or edit data/manual.json in a branch and open a pull request.
  • collector.py merges the entry into the public program list on the next scheduled run, after the validator accepts it.
